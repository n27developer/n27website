# N72 Investments Website

A professional static website for **N72 Investments**, a privately held investment firm based in Abu Dhabi, United Arab Emirates.

The website is designed with a premium institutional style using **HTML**, **Tailwind CSS CDN**, custom styling, Google Fonts, and professional investment-related imagery.

## Overview

N72 Investments focuses on principal investments, strategic transactions, and long-term capital allocation across public and private markets.

The website presents the firm’s profile, investment focus, mandate, and contact information in a clean one-page layout suitable for deployment on Vercel or any static hosting provider.
